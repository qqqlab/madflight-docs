# M5Stack StampFly

This is an alternative firmware for the M5Stack StampFly ESP32-S3 quadcopter

## Required Hardware

- M5Stack StampFly
- RC receiver with 6 channels for Roll, Pitch, Throttle, Yaw, Arm Switch, Flight Mode Switch
- Optional: Openlog SDCard logger
